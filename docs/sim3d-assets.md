# 3D asset credits

The rendered simulation scenes use the following third-party assets. None are
redistributed in this repository; `scripts/sim3d/fetch_assets.py` downloads them
into the git-ignored `storage/assets/` folder.

## Road users (CC BY 4.0)

Sketchfab models, obtained through the [Objaverse](https://huggingface.co/datasets/allenai/objaverse)
mirror. Licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
Changes made for this project: models are re-scaled to nominal real-world size, re-oriented,
stripped of importer bone-display shapes, and number plates (and, on two-wheelers, a simple
rider figure) are added at render time.
