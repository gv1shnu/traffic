# Data and model provenance

- **Object detection:** Ultralytics YOLO11n public pretrained weights, downloaded by Ultralytics from its official assets releases. Runtime reports include a weight checksum. [Tracking adapter documentation](https://docs.ultralytics.com/modes/track/) explains the persistent ByteTrack mode used here. Ultralytics software/models have AGPL/enterprise licensing terms; inspect upstream licensing before redistribution or a proprietary deployment.
- **Plate detector:** [Koushim/yolov8-license-plate-detection](https://huggingface.co/Koushim/yolov8-license-plate-detection), model-card license MIT, pinned revision `83c98fbe7412fe8b3950adb5637cfd08b0f04809`, SHA-256 `2d95861825bb4184404344c9cf809f40fd31dba785fe54e8ba5b9a3583789822`. The Ultralytics runtime has its own license. No Indian-specific accuracy is implied by this model.
- **OCR:** [JaidedAI EasyOCR](https://github.com/JaidedAI/EasyOCR), official English and CRAFT weights obtained through its downloader. Runtime inference disables downloads unless explicitly configured.
- **Indian validation sample:** [UVH-26](https://huggingface.co/datasets/iisc-aim/UVH-26), released by AIM @ IISc under CC BY 4.0. Attribution: Akash Sharma et al., *The Urban Vision Hackathon Dataset and Models: Towards Image Annotations and Accurate Vision Models for Indian Traffic*, UVH-26-v1.0, Indian Institute of Science, [arXiv:2511.02563](https://arxiv.org/abs/2511.02563), 2025. The source consists of Bengaluru CCTV images with vehicle annotations. `fetch_indian_sample.py` records the current repository revision, source URL and SHA-256 for every fetched image in an ignored local manifest. No source CCTV image is committed or shown in the README.
- **Synthetic fixtures:** Generated by `fixtures/synthetic.py` in this repository. Their geometry and labels are test inputs, never a production detector fallback. Videos are created locally and carry a visible synthetic-test label.

No new neural model was trained. Public weights provide actual inference; the India-specific work in this version is mixed-traffic configuration, road regions, plate formats and an explicitly scoped Indian evaluation sample. Domain fine-tuning remains a documented next step.
